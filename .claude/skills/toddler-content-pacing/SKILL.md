# Toddler (2–4) Pacing and Language Rules

Load this before writing `script.md`, `narration.md`, or `edit.md`. Source: `research/2026-09-toddler-niche.md` §4, backed by developmental-psychology research on the Ms. Rachel format.

## Language ("motherese")
- Sentences of 3–6 words. One idea per sentence.
- Basic, concrete vocabulary only — no abstractions, no idioms, no sarcasm.
- Repeat the episode's key word 3+ times per scene it appears in, and again at the end as a recap.
- Direct address to the viewer ("Can YOU find the red ball?") — not third-person narration about the character.

## Expectant pausing
- After every question or prompt to the viewer, hold a genuine 2–3 second silent pause before continuing — even in pre-recorded content. This is proven to increase toddler verbal output and engagement; do not cut it for pacing in editing.
- Mark every pause explicitly in `narration.md` as `[PAUSE 2-3s]` so `editor` preserves it in the EDL and doesn't trim it as "dead air."

## Structure and repetition
- The *structure itself* should repeat, not just the content: e.g. for format B, every single item must follow the identical beat pattern (AI clip → key word → real footage → key word repeated → transition). Predictability of structure is a feature for this age, not a flaw.
- Include one short, simple repeating song/chant (4–8 lines max, one repeated line) even in format A "story" episodes — pure narrative without any song underperforms for this age band per the research.
- End every episode with a recap that re-states the key word(s)/lesson one more time.

## Length
- Format A (story): 1.5–3 minutes total. Do not exceed this — attention drops sharply past it for this age.
- Format B (hybrid): 2–5 minutes per item; a full episode can chain 3–4 items up to 8–10 minutes, but each item must stand alone as a complete beat.
- Micro-episodes (single emotion/concept, ~90 seconds) are a valid and encouraged standalone format — also ideal for Shorts repurposing.

## Visual pacing (for editor/visual-prompter)
- No shot longer than ~6 seconds without a change (new angle, new element entering, color change) — toddlers disengage from static shots faster than older children.
- Cuts should be simple hard cuts or gentle fades — avoid fast whip-pans, strobing, or rapid-cut montage, which is both a poor fit for the age and a red flag for the "AI slop" pattern this project is explicitly avoiding.

## Emotional content rules
- Any "scary" or "worried" beat must resolve within the same scene or the next one — never leave a fear unresolved across a cut or scene break.
- One emotion per beat, exaggerated and named explicitly out loud ("Ember feels SCARED").
